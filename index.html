Supported operations

  • Extract Audio: Pull the audio track from any video file

Tips

    
    
      
  • First run downloads ffmpeg.wasm (~30MB) — subsequent runs are faster
    • 
      
  • Files under 100MB process fastest; very large files may run slowly on low-memory devices
    • 
      
  • Waveform mode works for any audio/video file without ffmpeg — instant and offline
    • 
      
  • Use Trim with stream copy for near-instant cuts of large files
